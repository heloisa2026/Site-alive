# Instituto Alíve | Desenvolvimento Web

**Projeto de desenvolvimento de uma plataforma institucional e comunitária.**

🌐 **[Acessar o site](https://site-alive.vercel.app)**

> "Cultive saber, transforme viver."

## 📖 Sobre o projeto

O Instituto Alíve é uma iniciativa voltada à transformação social, conectando pessoas e comunidades por meio de três pilares fundamentais: **Saúde, Cultura e Educação**.

Este projeto consiste no desenvolvimento de uma plataforma web institucional, criada para apresentar a organização, divulgar suas iniciativas e facilitar a interação com a comunidade.

O site reúne informações institucionais, projetos sociais, eventos, conteúdos informativos e canais de participação.

## 👩‍💻 Desenvolvimento

Este projeto foi desenvolvido por mim para o Instituto Alíve e integra meu portfólio pessoal como experiência prática em desenvolvimento web.

Minha participação envolveu a construção da aplicação, organização dos componentes, implementação das interfaces e desenvolvimento das funcionalidades da plataforma.

O projeto também representa minha experiência com tecnologias de desenvolvimento front-end e aplicação de conceitos de organização, componentização e experiência do usuário.

## ✨ Funcionalidades

- **Página institucional:** apresentação da organização, história e propósito.
- **Projetos sociais:** exposição e organização de iniciativas por categorias.
- **Eventos e inscrições:** divulgação de atividades e formulário de participação.
- **Galeria multimídia:** apresentação de registros das ações e atividades.
- **Participação comunitária:** espaços destinados a voluntários, doadores e parceiros.
- **Notícias e atualizações:** divulgação de informações e conteúdos institucionais.
- **Painel administrativo:** gerenciamento de projetos, eventos e notícias.
- **Interface responsiva:** adaptação da navegação para diferentes dispositivos.

## 🌿 Identidade do projeto

A plataforma foi estruturada visualmente a partir dos três pilares do Instituto:

| Pilar | Representação |
|---|---|
| Saúde | Verde |
| Cultura | Laranja |
| Educação | Amarelo |

A identidade visual busca transmitir acolhimento, conhecimento e transformação social, mantendo uma experiência de navegação organizada e intuitiva.

## 🛠️ Tecnologias utilizadas

- **React 19:** construção da interface por meio de componentes reutilizáveis.
- **TypeScript:** tipagem e organização do código.
- **Tailwind CSS v4:** estilização e construção de layouts responsivos.
- **Vite 6:** ambiente de desenvolvimento e ferramenta de build.
- **Motion:** animações e transições da interface.
- **Lucide React:** biblioteca de ícones.
- **Canvas Confetti:** efeitos visuais interativos.

## 🚀 Como executar localmente

### Pré-requisitos

- Node.js 18 ou superior
- npm

### Instalação

```bash
# Clonar o repositório
git clone URL_DO_REPOSITORIO

# Entrar na pasta
cd Site-alive

# Instalar dependências
npm install

# Iniciar o projeto
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
